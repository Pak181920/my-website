# Profo portfolio

A responsive project portfolio featuring the HK SIGS robotics project. The homepage includes a project banner with a layered scroll effect using `hksigs-back.svg` as the fixed event scene and `hksigs-front.svg` as the team and robot foreground. The foreground rises as the banner moves into view.

Edit `index.html` to update project details, portfolio copy, or links.

## Publish with GitHub Pages

This repository publishes from the `main` branch and root folder using GitHub Pages.

The published page is public. Avoid placing private information in the repository.
