# Your GitHub Pages website

This starter site is a single static page. Edit `index.html` to change the name, introduction, cards, about section, and contact email.

## Publish with GitHub Pages

1. Create a new repository on GitHub. On GitHub Free, make it public to use Pages.
2. Add `index.html` to the repository's top level and commit it to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`, and save.
5. Once deployment finishes, use the site link shown in **Settings → Pages**. A project site usually has an address like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

GitHub Pages hosts static websites. The published page is visible on the internet, so don't put private information in it.
